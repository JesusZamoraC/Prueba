Programa en Python

def saludar_clase(alumnos):
    for nombre in alumnos:
        print(f"Hola, {nombre}")

grupo = ["Ana", "Carlos", "Lucía"]
saludar_clase(grupo)

Para ejecutar este programa, abre la terminal pulsando Ctrl + Ñ, escribe el comando python programa.py y presiona la tecla Enter. Al ejecutarse, la consola mostrará la siguiente salida: Hola, Ana.
